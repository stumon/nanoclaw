项目1：FastEscrow 放款系统（2021-2023）

难点：

放款额度动态变化，需要实时根据用户额度和订单状态循环捞取订单
上游第三方结算不确定，部分订单已结算，需要释放额度重试
现有策略一次批量放款，额度利用率低，经常造成大量资金闲置

解决方案：

重新设计放款逻辑，引入动态比例分配，按订单状态实时调整额度
循环拉取订单直到额度用完或无合格订单，保证最大化额度利用
引入状态标记机制区分不同批次订单，避免重复放款

效果：

额度利用率显著提升，每笔订单放款接近最大可用额度
系统流程更稳定，减少人工干预和异常处理
放款效率与资金周转率提升，整体业务流程顺畅
项目2：分布式调度中心（2023-2024）

难点：

分布式系统多 pod 并发触发，需保证任务仅在单节点执行
高并发下任务调度精准度要求高（毫秒级触发）
支持跨语言调用（Go SDK + Java Server），保证执行结果可靠反馈

解决方案：

基于 DB 锁实现分布式任务唯一触发
构建时间循环队列，任务仅在距离下一次执行时间 5s 内进入队列，保证准时触发
双段式调度：Server 下发任务后结束本轮调度，SDK 执行并反馈结果，实现可靠性与解耦

效果：

系统支持上万 QPS，数万任务并发执行，几十个团队接入无冲突
任务准时触发，延迟低于设计阈值
提高调度系统可扩展性和稳定性
项目3：用户中心激活流程重构（2025-至今）

难点：

源代码长期迭代导致严重腐化，维护难度高
各国和产品逻辑通过大量 if/else 判断，新增产品或国家接入成本高
流程复杂且缺少可配置化管理

解决方案：

将激活流程改为配置化驱动，移除大量硬编码判断
通过抽象流程节点与状态机设计，实现快速新增国家和产品
优化核心模块结构，提高可维护性和可扩展性

效果：

日常维护效率显著提升，新增产品/国家接入周期大幅缩短
系统可读性和稳定性提高，减少因代码腐化导致的 bug
为未来扩展 AI/Agent 智能运营打下基础
